# 🥬 Sistema Hortfruit

Sistema de gestão para hortifrúti desenvolvido em Python, focado em rapidez no atendimento, controle de vendas e operação simplificada para pequenos comércios.

## 🚀 Funcionalidades

- Venda por peso (kg)
- Venda por unidade
- Pesquisa rápida de produtos
- Controle de caixa
- Histórico de vendas
- Dashboard administrativo
- Impressão térmica ESC/POS
- Operação por teclado
- Backup automático
- Sistema de licenciamento

## 🛠 Tecnologias

- Python
- SQLite
- PyInstaller
- ESC/POS
- Git
- GitHub
